# Contributing

Contributions are welcome. Please keep the public edition lightweight and suitable for small Raspberry Pi systems.

Before opening a pull request:

1. keep user-specific names, coordinates, domains, databases and logs out of commits;
2. preserve the Flask + SQLite + Leaflet architecture;
3. keep visible dashboard text in English;
4. test the empty-database startup path and the main JSON endpoints;
5. document new configuration variables in both `config.example.env` and `README.md`.

Bug reports should include the Raspberry Pi model, operating-system version, Python version and relevant service logs with private details removed.
